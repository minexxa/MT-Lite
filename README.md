# MT-Lite

轻量级双窗口文件管理器，灵感来自 [MT管理器](https://mt.cc)，基于 MT Manager 2.26.10 反编译分析后的重写实现。

使用 **Jetpack Compose** + **Kotlin** 构建，优先支持 Root 与 Shizuku。

> **范围声明**：本项目**完全不包含 APK 逆向修改功能**（无 dex / arsc 编辑、无 smali 反编译修改、无重新打包与签名、无资源注入）。APK 相关能力仅限**只读信息查看**与**系统安装器调用**。

## 功能

### 双窗口文件管理
- 左右独立面板，点击/长按切换活动窗口，活动窗口顶部高亮指示条
- 导航：后退 / 前进 / 上级 / 路径跳转 / 窗口同步 / 历史栈
- 每个窗口独立维护路径历史与排序

### 排序与显示
- 排序方式：名称 / 大小 / 修改时间 / 类型，支持升序降序
- 文件夹优先显示开关
- 显示 / 隐藏隐藏文件（`.` 开头）
- 按类型着色图标：文件夹、压缩包、APK、图片、视频、音频、文本、代码
- 显示修改时间、大小与权限位（Root/Shell 场景）

### 文件操作
- 复制 / 剪切 / 粘贴，粘贴时**冲突解决**（覆盖 / 跳过 / 保留两者）
- 多选（点击已选状态切换、全选、反选）、批量删除
- 重命名、批量重命名（查找替换，保留扩展名）
- 新建文件 / 文件夹
- chmod 权限修改（需 Root）
- **回收站**：删除默认移入 `/storage/emulated/0/.MT_Lite_Trash`，可清空
- 属性对话框：名称 / 路径 / 类型 / 大小 / 时间 / 权限 / APK 摘要

### 搜索
- 当前目录递归搜索（深度 12）
- 可按文件名匹配，或同时搜索文本文件内容（≤1MB）

### 压缩与解压
- 浏览 zip / apk / jar 内部（只读）
- 从选中项创建压缩包（可选密码）
- 向已有压缩包添加文件
- 解压整个压缩包或单个条目到指定目录
- 压缩包完整性测试
- 进度显示与取消

### 查看器与编辑器
- 文本编辑器：查找 / 替换全部、行数与字符统计、只读模式、自动换行
- 图片查看器（BitmapFactory 解码，只读）
- 十六进制查看器：分页浏览、偏移显示（只读）

### APK 工具（只读）
- APK 信息查看：包名 / 版本 / SDK / 大小 / 组件数量 / 签名 SHA-256、SHA-1、MD5 / 权限列表 / 安装时间
- 安装包提取：列出已安装应用并导出 APK 到 Download/MT-Lite-APK
- 调用系统安装器安装 APK

### 书签
- JSON 持久化（应用私有目录）
- 侧边栏直接跳转、删除，支持分组字段
- 独立书签管理页面

### 终端
- libsu shell 执行，命令历史快捷条（最近 10 条）、回车执行、清空输出

### 设置
- 主题：跟随系统 / 浅色 / 深色
- 显示隐藏文件、文件夹优先、默认排序、默认路径
- 回收站开关、删除前确认、编辑器自动换行
- Root / Shell 状态显示

## 技术栈

- Kotlin 2.0 + Jetpack Compose（Material 3）
- libsu (Root) / Shizuku API
- Zip4j（压缩包）
- SharedPreferences（设置）+ JSON 文件（书签）
- 仅编译 `arm64-v8a`

## 构建

```bash
./gradlew assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/`。
